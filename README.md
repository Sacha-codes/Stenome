# Stenome



##### **Text expansion tool, typing macro, or stenograph, whatever you want.**

###### Stenome is a Windows desktop application that lets you create custom text shortcuts to reduce repetitive typing. It can be used for everyday writing, frequently used phrases, and programming.





##### **Features**

* Custom shortcuts: Define short triggers that expand into longer text.
* Global text expansion: Use shortcuts while working in other applications.
* Personalized snippets: Manage your own collection of shortcuts.
* Lightweight desktop interface: Configure your snippets through a simple GUI.





##### **Installation**

* GitHub : download the StenomeSetup.exe file at github.com/Sacha-codes/Stenome


##### **Uninstalling**

* Uninstalling Stenome removes the application but preserves your saved snippets and settings. To remove them completely, delete the Stenome folder inside %APPDATA%.


##### **Technologies**

* Programming Language: Go
* GUI: Fyne
* Data Save: SQLite
* Keyboard hook: Windows



##### **Privacy**

Stenome operates entirely locally. It requires no internet access, collects zero telemetry, and your snippet data never leaves your machine.
